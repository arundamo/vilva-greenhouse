# Home Slideshow Images

Drop images into these folders to include them automatically on the Home page slideshow:
- src/assets/home-slideshow/greens -> shown in "OUR GREENS"
- src/assets/home-slideshow/farms -> shown in "OUR FARMS"

Naming suggestion (optional):
- greens-01.jpg, greens-02.jpg, ...
- farm-01.jpg, farm-02.jpg, ...

Notes:
- Supported formats: .jpg, .jpeg, .png, .webp
- New files are picked up by Vite automatically; if not, restart the dev server.
